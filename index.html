阅读约定 ​

  • 示例基于 Git 2.40+ 的常见行为编写，可直接照抄；输出中的哈希与路径以实际仓库为准。
  • 命令块以 # 开头的行是注释，不需要输入。
  • 「分支图」统一用 ASCII 或 SVG 表示：* 是提交，\ 与 / 表示分叉与汇合，括号内是分支名。
  • 新增章节的图解统一使用 SVG，颜色随明暗模式自动切换；图下会标注该图想说明的结论。
  • 涉及改写历史的操作（rebase、cherry-pick、reset --hard）都会用提示块标注风险与适用边界。

关于改写历史

本教程反复强调一条底线：已经被他人拉取的公共分支，不要 rebase，也不要 reset 后强推。协作篇第 13 章会用分支图解释这条规则为什么不是教条，而是数学结果。
